# Nithya's Portfolio

A single-page portfolio website showcasing my journey as a Computer Science graduate and aspiring AI Engineer.  
Built with **HTML, CSS, and JavaScript**, styled in a **blue theme** with the **Cormorant font family**.

---

## 🚀 Features
- **Hero Section**: Welcome message with background image.
- **About Me**: Introduction and career goals.
- **Skills**: Technical skills displayed with images (HTML, CSS, JavaScript, Python, SQL, PostgreSQL, Generative AI).
- **Soft Skills**: Communication, teamwork, problem-solving, adaptability, critical thinking.
- **Proof of Interest**: Links to projects, blogs, and GitHub repositories.
- **Contact**: Email, LinkedIn, and social media links.

## 📖 How to Run
1. Clone or download this repository.
2. Place all files in a folder called `portfolio`.
3. Open `index.html` in your browser.
4. (Optional) Host on **GitHub Pages** or **Netlify** for free.
